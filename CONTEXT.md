# Context

## Glossary

**Workshop**
The whole system of skills that moves work forward across the attached repos on a schedule: the timetable, the dispatcher, the surveys and dependency maintenance. Not "factory": that word only describes how it feels.

**Workshop board**
A read-only public page that shows every open issue and PR of the workshop, and the ones closed recently, sorted into the stage each one is in. Each card links to its issue or PR for detail. Decisions are never taken on it; they go through the digest.

**Digest**
The one issue in this repo where the maintainer sees what waits on them and answers it. The only place the workshop takes its decisions from.
