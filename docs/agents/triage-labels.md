# Triage Labels

This repo uses the workshop's labels, as every workshop repo does: see the `conventions` skill (`skills/conventions/SKILL.md`). It has no labels of its own.

Skills written for mattpocock/skills name five triage roles. They map as follows:

| Role | Here |
|---|---|
| `needs-triage` | no `ready-for-agent` yet |
| `needs-info`, `ready-for-human` | an open `## Decision needed` section |
| `ready-for-agent` | a tier label; the maintainer adds `ready-for-agent` itself |
| `wontfix` | close as `not planned` |
